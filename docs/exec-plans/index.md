# Execution plans

Plans are first-class artifacts. They are versioned next to the code, so an agent can pick up work without any
outside context. [PLANS.md](../PLANS.md) defines the format and the lifecycle.

| Location | Contents |
|---|---|
| [active/](active/index.md) | Plans in progress. Each one is restartable from the file alone |
| [completed/](completed/index.md) | Finished plans, kept for their decision logs and retrospectives |
| [tech-debt-tracker.md](tech-debt-tracker.md) | Known debt, gaps and missing guardrails, with priority |
