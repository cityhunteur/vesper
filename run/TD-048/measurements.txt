   MemTotal 220292 kB, MemFree 153876 kB, MemAvailable 152388 kB, nproc 1, cgroup 0::/workload.
   So the guest's own use is about 107 MiB; SizeOf adds 128 MiB to a limit.

2. Guest for a 512 MiB limit (648 MiB): the workload reads mem=596 (MiB MemTotal), memory.max=536870912.
   A 480 MiB anonymous block is filled; a 560 MiB block is killed (dd exit 137). A 600 MiB block is refused by the
   kernel before the limit acts (exit 1), because it is larger than the guest.

   Peak 1126 MiB under a 1271 MiB ceiling. The memory budget read committed=0 afterwards.
